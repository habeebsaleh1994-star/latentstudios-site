## Publication contract

One stored ZIP contains exactly `story.json` and `media/<fresh-public-UUID>.png` entries. There are no directories, compression, encryption, descriptors, ZIP64 extensions, comments or extra fields in the v1 dialect. Both local and central records must agree; paths, file count, offsets, CRCs, sizes, PNG chunks/dimensions and SHA-256 hashes are checked before preview.

| Field | Meaning |
|---|---|
| `format`, `version` | `ritual-story-publication`, integer `1` |
| `packageId` | Fresh public UUID for this export |
| `producer` | Allowlisted app name, version, build |
| `story` | Fresh public ID, exact title and standfirst, optional cover asset ID, ordered frames |
| frame | Fresh public ID, public asset ID, exact supported role, resolved caption plus source |
| caption source | `inherit`, `authored` or `silence`; silence requires empty text; unused seed captions never cross |
| asset | Fresh public ID and matching PNG path, MIME, width/height, bytes, SHA-256, `srgb` |
| `mediaPolicy` | `approved-rendered-srgb-png-without-source-metadata` |

No internal IDs, private collection name, intent notes, canvas coordinates, original/source paths, camera metadata, GPS, original photographs or unused seeds are serialized. Hashes establish package integrity, not a digital signature or provenance authentication.

Each approved image is redrawn into fresh 8-bit sRGB pixels, downscaled only when its longest side exceeds 2400px. Its authored crop is carried in the pixels; the exporter adds no new crop. PNG output admits only IHDR, a fixed sRGB marker, IDAT and IEND, removing even ImageIO-generated EXIF. No source metadata is copied.

Limits: 1–99 distinct sequenced photographs plus optional cover; 100 assets maximum; title/caption 500 UTF-16 units; standfirst 5000; source render at most 32 megapixels and 16000px on either edge; 30 MiB per encoded PNG; **60 MiB aggregate media** to fit existing release/portable-backup limits; 1 MiB manifest; 80 MiB hard archive limit. Unsupported content is rejected with an error, never truncated or silently omitted. The UI uses MB as its familiar label for these binary limits.

## Website interpretation and persistence

The import begins with a new home and project page. No sample works or invented biography/contact content are copied. Opening cover is the first project block and may repeat a sequenced frame. Adjacent left/right frames share a two-column desktop section and stack in source order on mobile. Breath uses reading width and extra spacing; full-bleed uses available page width. Orphan pair members stand alone. Every image starts at its approved original proportions. Captions preserve authored line breaks. Ten existing directions remain available for explicit preview.

The confirmation creates a fresh `?studio=<UUID>` workspace in `latent-studio-story-<UUID>` with a matching isolated broadcast channel. The document and all media commit in one IndexedDB transaction. Failure removes the incomplete new database. Current-draft writes are not used by the importer; pending current-draft edits must settle first. A separate local Story library stores shortcuts; if its write fails after a successful draft commit, the UI reports that and provides the recoverable draft URL. Unknown/missing Story addresses fail instead of seeding a replacement or opening the main draft.

Document v7 stores the allowlisted original public receipt, package hash and initial frame/block mapping as `sourcePublication`. Later edits affect the website, not that historical receipt. Backups/revisions preserve it, including across asset-ID collision remapping. Versions 1–6 migrate in memory; first save retains the exact old record as **Before Story imports**. Main and ten demo studios retain their prior database names. Release, delivery, website and editor links retain Story workspace scope.

Local browser storage is not cloud durability. Export a backup. This increment has no hosting, domains, billing, account creation, upload service, live sync or source-library mutation. It does not parse Ritual PDFs, read a live catalog, or infer an undocumented private format.
