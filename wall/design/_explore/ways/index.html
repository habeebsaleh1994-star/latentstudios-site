One series, four ways of moving

The same twelve photographs, in the same order, with the same pair, the same note beside the pine and the same pause. Nothing is restyled: type, colour and spacing are Folio's Quiet look throughout. Only the arrangement changes. Every frame is the real page; click one to use it.

What is being tested: whether a template can hold several arrangements without losing itself, because the document stores what the artist meant (this order, these two together, a pause here) and each arrangement reads it in its own way.

One addition was needed: in Book, a work can be marked to run across both pages (plates 01 and 08 here). The other arrangements ignore the mark.
